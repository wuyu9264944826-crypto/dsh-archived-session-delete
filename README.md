# 删除归档对话（DSH 插件）

在 DeepSeek Harness 的**已归档对话**右键菜单里加一条「删除对话」，确认后永久删除这条对话的本地记录。未归档的对话不会出现这一行。

> A DSH client+host bundle that adds **Delete conversation** to an archived Session's context menu and removes its stored log.

## 行为

| 项 | 说明 |
|---|---|
| 出现位置 | 会话右键菜单的最后一条（「取消归档」之后，分隔线以下），红色危险项 |
| 其它入口 | 行尾悬停的 `⋯` 按钮打开的是同一个菜单，所以也有这一条 |
| 不出现的情况 | 会话未归档；普通对话、置顶对话的菜单完全不变 |
| 点击后 | 弹一次确认框，写明「将永久删除『标题』及其本地会话记录，此操作无法撤销」；默认焦点在「取消」，Esc 或点遮罩可关闭 |
| 确认后 | 删除会话日志目录、它在所属工作区的归属、归档集合中的条目；该行立即从侧栏消失 |
| 反馈 | 成功弹一条「对话已删除」提示；失败时确认框保留并给出原因 |
| 语言 | 跟随 Harness 语言（中文 / 英文） |

## 删掉的是哪三样

| 目标 | 位置 |
|---|---|
| 会话日志 | `$DSH_HOME/sessions/<工作区分组>/<sessionId>/`（默认 `~/.dsh/sessions`） |
| 工作区归属 | `$DSH_HOME/storages/workspace.json` 里该工作区记录中的 `sessionIds` 条目 |
| 归档记录 | 同一文件的 `global.archivedSessionIds` 条目 |

## 安全约束

宿主侧（Node 进程）独立复核，浏览器的判断只决定「要不要显示这一行」：

- 会话必须在归档集合里，否则返回 `409 not-archived`；
- 会话不能还在运行（有活动 Agent），否则返回 `409 active`；
- 会话 id 必须是 `session-<uuid>` 形式，且只删除名字**完全等于**该 id 的目录；
- 路由只接受 `POST`，只服务回环地址上的请求，外来 `Origin` 一律拒绝。

## 安装

1. DSH → **插件** → **添加插件** → 选择这个目录（本地目录安装以 link 方式接入）；或
2. 让 agent 用 `plugin_manager` 的 `install_bundle`，目标填这个目录的绝对路径。

安装后插件行 id 为 `archived-session-delete`，客户端模块 id 为 `@local/archived-session-delete`。**安装完刷新一次窗口**（客户端模块在页面启动时加载），右键已归档对话即可看到这一条。

无需任何配置。

## 限制

- 删除是永久的，没有回收站、没有撤销。
- 只删这条对话本身；它的子代理会话不跟着删。
- 派生缓存（会话标题缓存）里该 id 的条目会留下，但已经不可达。
- 如果别的功能（定时任务、目标等）还引用这个会话 id，那边会变成指向空对象并各自报错。
- 需要侧栏的归档过滤处于显示归档的状态，才看得到归档行（这是 Harness 自身的归档视图行为）。
